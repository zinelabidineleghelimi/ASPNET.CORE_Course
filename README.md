# 🌐 ASP.NET Core Course — Learn ASP.NET Core from Zero to Advanced

Welcome to the **ASP.NET Core Course**! This repository teaches **web development with ASP.NET Core**, from **absolute beginner** to **advanced concepts**, using **C# and Razor pages**.

---

## 🎯 Course Goals
- Teach ASP.NET Core in a **structured and practical way**  
- Provide **hands-on examples and projects**  
- Prepare learners for **real-world web applications and enterprise development**  
- Build a strong foundation for **full-stack web development with .NET**  

---

## 📚 Course Roadmap & Lessons

### **01_Introduction**
- `what_is_aspnetcore` — Overview of ASP.NET Core framework  
- `installation_setup` — Installing Visual Studio, .NET SDK, creating first project  
- `first_web_app` — Creating and running a basic web app  
- `project_structure` — Understanding folders and files in ASP.NET Core  

### **02_Razor_Pages**
- `routing` — Routing in Razor Pages  
- `pages_models` — PageModel and code-behind concepts  
- `html_helpers` — Using HTML helpers in Razor Pages  
- `forms_and_validation` — Forms, model binding, and validation  

### **03_MVC_Basics**
- `models` — Creating models for your app  
- `views` — Creating views with Razor syntax  
- `controllers` — Writing controllers and actions  
- `routing_mvc` — Routing and URL patterns  

### **04_Data_Access**
- `entity_framework_core` — Introduction to EF Core  
- `dbcontext` — Using DbContext for database operations  
- `crud_operations` — Creating, reading, updating, deleting data  
- `migrations` — Database migrations and updates  

### **05_Services_Dependency_Injection**
- `register_services` — Registering services in Startup.cs  
- `dependency_injection` — Using DI in controllers and pages  
- `scoped_singleton_transient` — Service lifetimes explained  

### **06_Authentication_Authorization**
- `identity_setup` — Setting up ASP.NET Core Identity  
- `login_register` — User registration and login  
- `roles_policies` — Role-based authorization  
- `jwt_authentication` — JWT token-based authentication  

### **07_API_Development**
- `rest_api_basics` — Creating a REST API with ASP.NET Core  
- `get_post_put_delete` — Implementing CRUD endpoints  
- `api_routing` — Route configuration for APIs  
- `api_versioning` — Versioning APIs  

### **08_API_Generation**
- `openapi_swagger` — Generate API documentation with OpenAPI/Swagger  
- `swagger_ui_setup` — Set up Swagger UI for interactive API testing  
- `nswag_tooling` — Using NSwag to generate client SDKs  
- `api_documentation_best_practices` — Writing clear and maintainable API docs  

### **09_Advanced_Features**
- `middleware` — Creating custom middleware  
- `filters` — Using filters in controllers  
- `logging` — Logging with built-in providers  
- `error_handling` — Exception handling and error pages  

### **10_Frontend_Integration**
- `bootstrap_integration` — Using Bootstrap for UI  
- `javascript_ajax` — Client-side interaction with JS and AJAX  
- `vue_react_integration` — Optional SPA frameworks integration  

### **11_Projects**
- `blog_app` — Create a basic blog application  
- `ecommerce_app` — Build a simple e-commerce site  
- `task_management_app` — Task tracker with CRUD operations  
- `rest_api_project` — REST API backend with database  
- `identity_auth_app` — User authentication and roles demo
